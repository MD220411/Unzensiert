# Entscheidungen

Je Entscheidung eine kurze Datei `NNNN-titel.md` nach dem Muster von
[0000-vorlage.md](0000-vorlage.md), fortlaufend nummeriert. Eine Datei wird angelegt, wenn
sich Aufbau, eine öffentliche Schnittstelle, ein Dateiformat oder eine Abhängigkeit ändert.
Alte Dateien werden nicht umgeschrieben; eine neue Entscheidung nennt die, die sie ablöst.
