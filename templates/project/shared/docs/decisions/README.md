# Decisions

One short file `NNNN-title.md` per decision, following the pattern of
[0000-template.md](0000-template.md), numbered in order. A file is created when the
structure, a public interface, a file format or a dependency changes. Old files are not
rewritten; a new decision names the one it replaces.
